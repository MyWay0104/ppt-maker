# DESIGN — ppt-maker 기본

- 바탕은 순백 대신 미색(`canvas`)으로 화면 눈부심을 줄인다.
- 강조색(`primary`)은 한 장면에 한두 곳만 쓴다.
- 카드는 테두리(`hairline`) + 옅은 그림자로 구분한다. 두꺼운 그림자는 쓰지 않는다.

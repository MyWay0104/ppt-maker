# qa-gate — QA 게이트와 눈 검수

HTML을 고칠 때마다 아래 순서로 돈다. 높음이 0건이 되기 전에는 사용자에게 검토를 요청하지 않는다(게이트 B).

## 1. 순서

| # | 명령 | 보는 것 | 실패 시 |
|---|---|---|---|
| 1 | `build_present.py topics/<slug>` | present.html 재생성(파생 파일이 첫 단계) | 추출 오류 수정 |
| 2 | `validate_topic.py topics/<slug>` | 필수 파일, 게이트 A, 마커·연번, 금지 문자열, 허용 타입, 노트 | exit 1 |
| 3 | `qa_check.mjs topics/<slug>` | 넘침·잘림·겹침(SVG 안은 제외)·명암비·글자 하한·외부 요청(전체 장면) | 높음 → exit 1 |
| 4 | `deck/qa_rules.py topics/<slug>` | `deck-rules.json` 하우스 룰(금지어·말투·출처·시간 표기) | exit 1 |
| 5 | `export_pdf.mjs topics/<slug> --shots-only` | `_work/shots/slide-NN.png` (PDF와 같은 렌더) | — |
| 6 | 눈 검수(`deck-reviewer` post) | 아래 3절 체크리스트 | 높음·중간 반영 |
| 7 | `build_present.py topics/<slug> --check` | 끝에 최신 확인 | 1로 돌아감 |

스크립트는 모두 `${CLAUDE_SKILL_DIR}/scripts/` 아래에 있다. 장면 일부만 고쳤으면 3번에 `--slides 3,5-7`을 줄 수 있지만, 사용자 검토 요청 직전에는 반드시 전체 장면으로 돈다.

## 2. 심각도

| 심각도 | 기준 |
|---|---|
| 높음 | 잘림·넘침·겹침·깨짐, 글자 하한 미만, 명암비 미달, 오탈자, 사실 오류, 요청 위반, 외부 요청 |
| 중간 | 눈에 띄는 정렬 이상, 큰 빈 공간, 어색한 줄바꿈, 말투 불일치 |
| 낮음 | 미세 조정, 자동 계산 불가 항목(그라데이션 위 명암비) 확인 |

## 3. 눈 검수 체크리스트 (기계가 못 잡는 것)

스크린샷을 한 장씩 모두 연다. 20장 넘으면 앞·뒤 절반으로 나눠 두 검토자가 본다.

1. **세로 무게 중심** — `qa_check`가 `세로 빈 띠`(중간)로 먼저 알린다: 위아래 빈 띠 각 150px 이상, 또는 요소 사이 150px 이상. 고칠 때는 `margin-top: auto`로 벌리지 말고 간격·카드 안 여백을 늘려 묶음을 키운다. 그 밖에 내용 블록 아래 빈 높이가 위 여백(제목 아래~내용 시작)의 2배 이상이면 중간, 3배 이상이면 높음. 반대(아래 쏠림)도 같다
2. **빈 여백 덩어리** — 장면 넓이의 1/4 이상이 비어 있고 의도한 여백(표지·인용)이 아니면 중간
3. **고아 줄바꿈** — 마지막 줄에 4글자 이하만 떨어지면 중간
3-b. **의미 단위 줄바꿈** — 제목·부제·상자 글자에서 한 덩어리 말(`발표자 창`, `인정 욕구`)이 두 줄로 갈리면 중간. 고칠 때는 문장을 줄이거나 어순을 바꾸고, 상자 폭은 "높이 증감 0"으로 조정한다
4. **격자 간격 불균형** — 같은 역할 카드끼리 간격 차이가 8px 이상이거나 높이가 다르면 중간

PDF 자체를 그림으로 열 도구(poppler)가 없으면 5번의 `_work/shots/`로 검수한다. PDF는 같은 화면을 같은 크기로 찍은 것이라 결과가 같다. PDF 파일을 못 봤다고 검수를 미루지 않는다.
5. 정렬 — 기준선 어긋남, 아이콘·로고 위치, 캡션과 그림 거리
6. 일관성 — 같은 역할 요소가 장면마다 같은 자리·같은 크기
7. 가독성 — 강의실 뒤에서 읽히는 크기와 대비
8. 하우스 룰 — 말투, 시간 표기, 출처, 사내 정보가 화면에 남았는지

## 4. 내용 검수

- `python ${CLAUDE_SKILL_DIR}/scripts/deck/dump_deck_text.py topics/<slug>`로 화면 글자·노트를 뽑아 본다
- 수정 요청이 빠짐없이 반영됐는가, 제목이 내용을 대표하는가, 흐름이 이어지는가, 화면과 노트가 어긋나지 않는가
- 잔존 검사 범위: 본문 + alt·aria-label·title·라벨·HTML/CSS 주석·사양 문서

```markdown
| 장면 | 내용 | 선택지 |
```

## 6. 지표가 나빠졌을 때

높음이 갑자기 늘면 새로 고치기 전에 이전 버전(`overview.html.bak`, 직전 커밋)과 대조해 무엇이 원인인지 먼저 찾는다.

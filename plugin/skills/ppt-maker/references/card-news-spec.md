# card-news-spec — 카드뉴스 스펙 (보관용, 현재 범위 밖)

ppt-maker는 16:9 덱만 만든다. 인스타그램 카드뉴스를 요청받으면 "현재 지원하지 않는다"고 알리고, 필요하면 아래 스펙을 바탕으로 별도 작업을 제안한다.

## 규격

| 변형 | 크기 | 비율 | 쓰임 |
|---|---|---|---|
| portrait(기본) | 1080×1350 | 4:5 | 피드에서 가장 크게 보임 |
| square | 1080×1080 | 1:1 | 어디서나 같은 크기 |

- 카드 10장 이하, 카드 하나에 메시지 하나
- 글자가 크다(본문 40px 이상), 시각 요소가 강하다(사진·흐림 배경·큰 글자)

## 카드 타입 4종

| 타입 | 구성 |
|---|---|
| `photo-cover` | 전면 사진 + 브랜드·출처 검정 상자 + 아래 큰 헤드라인 |
| `video-cover` | 배경 영상 + 덮개 카드 + 아래 큰 헤드라인(정지 이미지로 낼 때는 대표 프레임) |
| `stat` | 큰 숫자 하나 + 라벨 + 짧은 설명 |
| `image-feature` | 이미지 틀 + 흐림·그라데이션 배경 + 헤드라인 + 본문 |

## 덱과 다른 점

- 장면 크기가 달라 `slide-types`·`qa_check`의 1920×1080 전제를 그대로 쓸 수 없다
- 지원하려면 템플릿·캔버스 크기 설정·허용 타입 목록을 따로 두어야 한다(덱 타입과 섞지 않는다)

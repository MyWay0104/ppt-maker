# 사람 세션 수동 체크리스트

자동 평가(`claude -p`)에는 AskUserQuestion이 없어서 게이트 A·C의 "사람 승인" 규칙을 확인할 수 없다. 아래 항목은 사람이 직접 대화형 세션에서 확인한다.

## 준비

1. 저장소 루트에서 `claude --plugin-dir ./plugin`으로 새 세션을 연다(다른 세션의 기억이 섞이지 않게 `/clear` 뒤 시작).
2. `evals.json` 케이스 1 또는 2의 프롬프트를 그대로 붙여 넣는다. 케이스 2는 "그냥 바로 만들어줘"가 들어 있어 (a)를 시험하기 좋다.
3. 질문에는 평소처럼 답하되, BRIEF 승인 질문에서는 먼저 "수정할 것 있음"을 한 번 골라 승인 전 상태를 관찰한다.

## 확인 항목

| # | 항목 | 확인 방법 | 결과 |
|---|---|---|---|
| a | "알아서 바로", "질문 한 번만"이라고 해도 AskUserQuestion이 최소 1회(BRIEF 승인) 나온다 | 화면에 선택형 질문이 뜨는가 | |
| b | 승인 전에는 overview.html이 없다 | "수정할 것 있음"을 고른 직후 `topics/<slug>/`를 본다 | |
| c | 승인을 고른 뒤에만 BRIEF가 `status: confirmed`가 된다 | 승인 전후 BRIEF front matter 비교 | |
| d | 검토 단계에서 "PDF 뽑아줘"라고 하면 AskUserQuestion으로 "최종 확인으로 볼까요?"를 되묻고 export하지 않는다 | 되묻는 질문이 뜨는가, `exports/`에 PDF가 생기지 않는가 | |
| e | 정확히 "최종 확인"이라고 말한 뒤에만 `export_approved: true`가 되고 PDF가 생긴다 | BRIEF 값과 `exports/<slug>.pdf` | |
| f | "질문 한 번만"이라고 했을 때 라운드 1·2가 한 번으로 합쳐지고, 승인 질문은 따로 남는다 | 질문 횟수를 센다 | |
| g | intake에서 스토리라인·꼭 넣을 내용을 묻는다 | 질문 내용 | |
| h | 요청 장수를 내용 장수로 보고 표지·구간 표지 수를 스토리보드 확인 때 알린다 | 스토리보드 확인 메시지 | |
| i | 이미지 요청에 후보를 보여 주고 승인한 것만 넣는다(출처 줄 포함) | 후보 질문, `assets/img/SOURCES.md` | |
| j | 장면 수정 뒤 스크린샷을 열어 확인한다 | transcript의 PNG Read | |

## 기록

결과는 `docs/p7-live-run-<날짜>.md`에 P6 기록표 형식(항목·결과·증거·분류)으로 남긴다. 산출 덱은 `topics/`에서 지우거나 참고용으로 표기한다.

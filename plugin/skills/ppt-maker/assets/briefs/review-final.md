## A·B. 시각 검토 (A: {{START}}–{{MID}}쪽 / B: {{MID+1}}–{{END}}쪽)

topic: topics/{{SLUG}}
mode: post

너는 발표자료의 마지막 시각 검토를 맡는다. `topics/{{SLUG}}/_work/shots/slide-NN.png`를 담당 범위에서 한 장씩 모두 연다.

### 이 덱의 디자인 규칙 (결함으로 보지 않을 것)

{{테마·색·여백·자리표시 등 의도한 규칙}}

### 볼 것

1. 기계가 못 잡는 4가지 — 수치로 판정한다
   - 세로 무게 중심: 내용 블록 아래 빈 높이가 위 여백(제목 아래~내용 시작)의 2배 이상이면 중간, 3배 이상이면 높음. 장면마다 위·아래 빈 높이를 px로 적는다
   - 빈 여백 덩어리: 장면 넓이의 1/4 이상이 비어 있고 의도한 여백(표지·인용)이 아니면 중간
   - 고아 줄바꿈: 마지막 줄에 4글자 이하만 떨어지면 중간
   - 격자 간격 불균형: 같은 역할 카드끼리 간격 차이 8px 이상 또는 높이가 다르면 중간
2. 정렬(기준선, 아이콘·로고 위치, 캡션과 그림 거리)
3. 글자(오탈자, 깨짐, 겹침, 잘림)
4. 가독성(강의실 뒤에서 읽히는 크기와 대비)
5. 하우스 룰 위반이 화면에 남았는지({{예: 시간 표기·말투·출처}})
6. 일관성(같은 역할 요소가 장면마다 같은 자리·크기)

### 출력

`topics/{{SLUG}}/_work/review/final-{{A|B}}.md`

- 장면별 한 줄 판정: `NN쪽 · 통과` 또는 `NN쪽 · 수정 필요 — 요약`
- "## 수정 요청" 표: 번호 · 쪽 · 요소 · 현재 상태 · 제안(구체적으로) · 심각도
- 끝에 "수정 필요: 높음 N · 중간 N · 낮음 N"

심각도: 높음 = 잘림·겹침·깨짐·오탈자·요청 위반 / 중간 = 눈에 띄는 정렬 이상·큰 빈 공간·어색한 줄바꿈 / 낮음 = 미세 조정

## C. 내용 검토

topic: topics/{{SLUG}}
mode: post

### 읽을 것

1. `topics/{{SLUG}}/_work/deck_text.md` — 주 자료
2. 비교가 필요할 때만 수정 전 덤프, 화면 모양이 필요할 때만 스크린샷
3. BRIEF 4절(사실 경계)

### 볼 것

1. 이번 수정 요청이 빠짐없이 반영됐는가(남은 곳을 쪽·문구로)
2. 말투 품질(일관성, 어색한 문장, 너무 길어진 화면 문장)
3. 제목이 내용을 대표하는가
4. 잘못된 정보·목적에 어긋나는 표현이 생기지 않았는가
5. 흐름(구간 사이가 노트로 이어지는가, 마지막 장이 닫는가)
6. 화면과 노트의 어긋남

### 출력

`topics/{{SLUG}}/_work/review/final-C.md`

- "## 전체 판정" 5~8줄
- "## 수정 요청" 표: 번호 · 쪽(장면 ID) · 화면/노트 · 현재(정확한 문구) · 요청(정확한 새 문구) · 심각도 · 이유
- "## 보류(사용자 확인)"
- 끝에 "수정 필요: 높음 N · 중간 N · 낮음 N"

# house-style — 디자인 파일이 없을 때의 기본 방향

`DESIGN.md`가 주어지지 않았을 때 출발점이다. 내용에 맞지 않으면 무엇이든 바꾼다.

## HTML을 쓰기 전에

1. **내용을 진짜로 채운다.** 레시피 장면이면 실제 재료가, 대시보드 장면이면 실제 수치가 들어간다. "항목 1, 항목 2" 같은 자리 채움은 초안에도 쓰지 않는다.
2. **팔레트를 먼저 정한다.** 밝은 바탕인가 어두운 바탕인가. 바탕·글자·강조 세 색을 코드보다 먼저 선언한다.
3. **글꼴 역할을 정한다.** 기본은 Paperlogy(제목·본문) + JetBrains Mono(코드). 굵기 대비로 위계를 만든다(`typography.md`).

## 되묻기 목록 — 흔한 AI 디자인 버릇

아래는 모든 LLM이 제일 먼저 손대는 패턴이다. 쓰려는 순간 "이 내용을 위해 고른 것인가, 습관인가"를 묻는다.

- 그라데이션 글자(`background-clip: text` + gradient)
- 카드 왼쪽 가장자리 강조 띠
- 어두운 바탕 + 청록색 / 보라→파랑 그라데이션 / 네온 강조
- 순수 `#000`·`#fff`(강조색 쪽으로 살짝 물들인다)
- 같은 크기 카드의 반복 격자
- 모든 것을 같은 무게로 가운데 정렬(시선이 갈 곳을 하나 만든다)

내용이 정말로 요구하면 써도 된다. 엄숙한 클로징의 가운데 정렬, 실제 제품 UI를 흉내 내는 카드처럼. 목표는 피하기가 아니라 **의도**다.

## 색

- 밝기는 내용에 맞춘다: 음식·건강·아이·교육 → 밝게 / 기술 발표·영화·금융 → 어둡게도 가능
- 강조색은 한 색. 모든 장면의 바탕은 같게
- 회색은 강조색 쪽으로 살짝 물들인다(아주 약한 온기·냉기라도 죽은 회색보다 낫다)
- 명암비: 본문 4.5:1, 큰 글자 3:1 이상. `qa_check.mjs`가 검사한다. 장식을 지워도 글자가 읽혀야 한다
- 팔레트를 먼저 선언하고, 요소마다 새 색을 지어내지 않는다

## 바탕 층 (선택)

장면이 비어 보이면 장식 층을 2~3개 둔다. 슬라이드는 움직이지 않으므로 **정지 상태로 완성된 모양**이어야 한다.

- 강조색을 옅게 물들인 radial glow(투명도 낮게)
- 주제어를 아주 크게, 3~8% 투명도로 깐 배경 글자
- 가는 선(hairline), 격자, 기하 도형
- 주제에 맞는 장식(데이터 장면의 눈금선, 교육 장면의 공책 줄 등)

장식은 글자와 겹쳐도 명암비를 해치지 않게 하고, `aria-hidden="true"`를 붙인다.

## 팔레트 고르기

바탕·글자·강조 세 색을 먼저 정한다.

| 분류 | 어울리는 내용 | 파일 |
|---|---|---|
| Bold / Energetic | 제품 출시, 공지, 행사 | `palettes/bold-energetic.md` |
| Warm / Editorial | 이야기, 사례 연구, 독서모임 | `palettes/warm-editorial.md` |
| Dark / Premium | 기술, 금융, 고급 브랜드 | `palettes/dark-premium.md` |
| Clean / Corporate | 설명, 튜토리얼, 사내 교육 | `palettes/clean-corporate.md` |
| Nature / Earth | 지속 가능성, 야외, 자연 | `palettes/nature-earth.md` |
| Neon / Electric | 게임, 기술 행사 | `palettes/neon-electric.md` |
| Pastel / Soft | 생활, 건강, 유아 | `palettes/pastel-soft.md` |
| Jewel / Rich | 행사, 격식 있는 자리 | `palettes/jewel-rich.md` |
| Monochrome | 글자 중심, 극적인 발표 | `palettes/monochrome.md` |

팔레트 파일은 5색 묶음 여러 줄이다. 한 줄을 골라 가장 밝은(또는 가장 어두운) 색을 바탕, 반대쪽 끝을 글자, 채도가 가장 높은 색을 강조로 둔다. 또는 OKLCH로 색상(hue) 하나를 정해 명도만 달리해 바탕·글자·강조를 만든다.

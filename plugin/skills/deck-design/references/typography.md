# typography — 슬라이드 글꼴과 조판

## 기본 글꼴 (오프라인 동봉)

| 역할 | 글꼴 | 굵기 |
|---|---|---|
| 제목·본문(한글·영문) | Paperlogy | 400·500·600·700·800 |
| 코드·명령어·파일 경로 | JetBrains Mono | 400 |

모두 `deck-design/assets/fonts/`에 woff2로 있고 topic으로 복사된다. 외부 CDN은 쓰지 않는다.

새 글꼴이 꼭 필요하면

1. 내용의 말투(공식 보고 / 개인 고백 / 기술 정밀 / 가벼운 농담)를 먼저 정한다
2. woff2 파일을 topic `assets/fonts/`에 넣고 `fonts.css`에 `@font-face`를 추가한다
3. 배포 가능한 라이선스(OFL 등)인지 확인하고 BRIEF 6절에 출처를 적는다

## 버릇처럼 고르는 글꼴 (되묻기)

Inter, Roboto, Open Sans, Noto Sans, Lato, Poppins, Montserrat, Playfair Display 같은 기본값은 모든 LLM이 가장 먼저 고른다. 쓰려면 "이 내용을 위해 고른 것인가"를 한 번 묻는다. 한글 덱은 Paperlogy 한 가족으로 굵기 대비를 주는 편이 대개 낫다.

## 지켜야 할 것

- **비슷한 산세리프 두 개를 섞지 않는다.** 한 가족의 두 굵기, 또는 산세리프 + 고정폭(코드)처럼 확실히 다른 조합만
- **굵기 대비는 크게.** 400 대 700이 아니라 500 대 800. 멀리서도 위계가 보여야 한다
- **발표 크기, 웹 크기 아님.** 본문 36~44px, 제목 72px 이상, 라벨·출처·꼬리말도 **24px 미만 금지**(인포그래픽 상자 글자는 32px)
- **여유는 간격에 쓴다.** 공간이 남아도 글자를 키우지 말고 줄 간격·요소 간격을 늘린다
- **한 장면에 표현적인 글꼴은 하나.** 하나가 주연이면 나머지는 조연

## 한글 조판

- `word-break: keep-all` — 한글 단어 중간에서 줄이 끊기지 않게
- `text-wrap: balance`(제목) / `text-wrap: pretty`(본문) — 마지막 줄에 한두 글자만 남는 고아 줄을 줄인다
- `<br>`로 줄을 끊지 않는다. 문장을 줄이거나 `max-width`를 조정한다
- 제목 자간: 큰 크기에서 `-0.02em ~ -0.04em`
- 줄 간격: 제목 1.1~1.25, 본문 1.4~1.55
- 괄호·따옴표가 줄 첫머리에 홀로 오지 않게 문장을 다듬는다

## 어두운 바탕 보정

밝은 글자를 어두운 바탕에 두면 두 가지 착시가 생긴다.

- **더 굵어 보인다.** 본문은 한 단계 가늘게(600 → 500)
- **자간이 좁아 보인다.** 줄 간격을 0.05~0.1 늘리고, 큰 제목은 자간을 0.01em 더한다

## 숫자·코드용 OpenType 기능

```css
/* 세로로 쌓인 숫자의 자릿수를 맞춘다 — stat 장면, 표, 시간 */
.stat-value, .data-column, .time { font-variant-numeric: tabular-nums; }

/* 1/2를 ½처럼 */
.ratio { font-variant-numeric: diagonal-fractions; }

/* 약어·단위를 덜 튀게 */
.unit { font-variant-caps: all-small-caps; }

/* 코드에서 fi·fl 합자 끄기 */
code, .code { font-variant-ligatures: none; font-family: "JetBrains Mono", monospace; }
```

`tabular-nums`는 숫자를 세로로 쌓을 때마다 켠다. 끄면 자릿수 폭이 달라 열이 어긋난다.

## 글꼴 고르는 생각법

1. **말투를 이름 붙인다.** 기관의 권위인가, 개인의 고백인가, 기술의 정밀함인가
2. **물건으로 떠올린다.** 박물관 캡션, 손으로 그린 가게 간판, 1970년대 단말기 설명서, 값싼 종이에 찍은 그림책 — 말투에 맞는 물건이 맞는 서체 종류를 가리킨다
3. **첫 직감을 의심한다.** 처음 떠오른 서체는 대개 학습 데이터의 기본값이다
4. **분류 공식을 깬다.** 편집물이라고 세리프, 기술이라고 고정폭일 필요는 없다

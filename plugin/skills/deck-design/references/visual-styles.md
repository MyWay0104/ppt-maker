# visual-styles — 이름 붙은 시각 스타일 8종

실제 그래픽 디자인 전통에 뿌리를 둔 스타일이다. "깔끔하게", "강렬하게" 같은 막연한 말 대신 덱에 분명한 성격을 준다.

- **고르는 법:** 분위기 먼저, 내용은 그다음. "청중이 무엇을 느껴야 하나?"를 묻는다.
- **쓰는 법:** 스타일 원칙을 구체적인 결정(팔레트·글꼴·배치·장식)으로 옮겨 `_work/visual_plan.md`에 적는다.
- 슬라이드는 정지 화면이다. 원래 스타일의 움직임 성격은 **배치의 리듬과 여백**으로 번역한다.

## 한눈에 보기

| 스타일 | 분위기 | 어울리는 덱 |
|---|---|---|
| Swiss Pulse | 정밀, 절제 | 데이터·개발 도구·지표 보고 |
| Velvet Standard | 고급, 차분 | 경영 보고, 기조연설, 투자 설명 |
| Deconstructed | 거칠고 산업적 | 기술 발표, 보안, 도발적 주제 |
| Maximalist Type | 크고 시끄러움 | 대형 발표, 이정표 공지 |
| Data Drift | 미래적, 몰입 | AI·ML, 첨단 기술 |
| Soft Signal | 친밀, 따뜻 | 건강, 개인 이야기, 생활 |
| Folk Frequency | 문화적, 선명 | 소비자 서비스, 음식, 공동체 |
| Shadow Cut | 어둡고 영화적 | 극적 공개, 조사 결과 |

## 1. Swiss Pulse — 요제프 뮐러브로크만

- 색: 검정(`#1a1a1a`)·흰색 + 강조 하나(전기 파랑 `#0066FF` 또는 호박색 `#FFB300`)
- 글꼴: 굵은 산세리프 제목, 보통 굵기 라벨. 숫자는 크게(96~140px)
- 배치: 보이지 않는 12열 격자에 모든 요소를 붙인다. 장식 없음
- 피할 것: 둥근 모서리 남발, 그림자, 장식용 아이콘

## 2. Velvet Standard — 마시모 비넬리

- 색: 검정·흰색 + 깊은 강조 하나(짙은 남색 `#1a237e` 또는 금색 `#c9a84c`)
- 글꼴: 가는 산세리프, 영문은 대문자 + 넓은 자간(0.15em 이상)
- 배치: 넉넉한 빈 공간, 대칭, 가운데 축. 한 장면에 한 가지 생각
- 피할 것: 빽빽한 불릿, 원색 여러 개

## 3. Deconstructed — 네빌 브로디

- 색: 짙은 회색(`#1a1a1a`), 녹슨 주황(`#D4501E`), 거친 흰색(`#f0f0f0`)
- 글꼴: 두껍고 산업적. 기울이거나 가장자리를 넘는 제목
- 배치: 겹침·어긋남을 의도적으로. 주사선·질감 장식
- 피할 것: 매끈하게 다듬은 카드. 단, 본문 가독성과 명암비는 지킨다

## 4. Maximalist Type — 폴라 셰어

- 색: 채도 높은 빨강(`#E63946`)·노랑(`#FFD60A`)·검정·흰색, 최대 대비
- 글꼴: 글자가 곧 그림. 크기·각도가 다른 글자 층이 화면의 50~80%
- 배치: 빈 바탕 없이 글자로 채운다. 장면당 메시지 하나
- 피할 것: 작은 글자 설명문(다음 장면으로 넘긴다)

## 5. Data Drift — 레픽 아나돌

- 색: 깊은 검정(`#0a0a0a`), 전기 보라(`#7c3aed`), 청록(`#06b6d4`)
- 글꼴: 가볍고 미래적인 가는 산세리프, 글자 수 최소
- 배치: 극단적인 크기 대비(아주 작은 라벨 ↔ 아주 큰 숫자), 점·선으로 데이터 흐름 표현
- 피할 것: 네온 남발(`house-style.md` 되묻기 목록). 글자는 명암비 우선

## 6. Soft Signal — 슈테판 자그마이스터

- 색: 따뜻한 호박색(`#F5A623`), 크림(`#FFF8EC`), 먼지 낀 장미(`#C4A3A3`), 세이지(`#8FAF8C`)
- 글꼴: 손글씨 느낌 또는 인문주의 세리프, 부드럽고 섬세하게
- 배치: 한 요소가 화면을 채우는 가까운 구도. 회사 보고서처럼 보이지 않게
- 피할 것: 표·격자 카드

## 7. Folk Frequency — 에두아르도 테라사스

- 색: 진분홍(`#FF1493`), 코발트(`#0047AB`), 해 노랑(`#FFE000`), 에메랄드(`#009B77`)
- 글꼴: 굵고 둥근 서체. 패턴과 반복
- 배치: 층을 겹친 풍성한 질감, 손으로 만든 느낌
- 피할 것: 네 색을 한 장면에 모두 크게 쓰기(한 장면 주색은 둘)

## 8. Shadow Cut — 한스 힐만

- 색: 깊은 검정(`#0a0a0a`), 차가운 회색(`#3a3a3a`), 흰색 + 강조 하나(핏빛 `#C1121F` 또는 독성 초록 `#39FF14`)
- 글꼴: 필름 누아르 제목처럼 날카롭게, 강한 대비
- 배치: 어둠 속에서 떠오르는 요소, 공개(reveal)가 곧 이야기
- 피할 것: 밝은 카드, 부드러운 그림자

## 분위기 → 스타일

| 내용의 느낌 | 스타일 |
|---|---|
| 데이터 중심, 분석적, 기술적 | Swiss Pulse |
| 고급, 경영, 격식 | Velvet Standard |
| 거칠고 도발적 | Deconstructed |
| 대형 발표, 들뜬 분위기 | Maximalist Type |
| AI·미래 기술 | Data Drift |
| 사람 중심, 따뜻함, 건강 | Soft Signal |
| 문화, 재미, 소비자, 축제 | Folk Frequency |
| 어둡고 극적, 조사 발표 | Shadow Cut |

## 나만의 스타일 만들기

8종은 예시일 뿐이다. 새로 만들 때는 다음 순서로 적는다.

1. **이름** — 디자이너·예술 운동·문화적 참조
2. **팔레트** — 2~3색, hex 값 명시
3. **글꼴** — 한 가족, 두 굵기. 각 굵기의 역할
4. **배치 규칙** — 격자인가 자유 배치인가, 여백은 넉넉한가 빽빽한가
5. **피할 것** — 이 스타일에서 하면 안 되는 것 2~3개
